# 切换音色与使用自己的声音

版本0.3.0。语音合成、参考录音处理都在这台电脑完成，无需云端声音克隆账户。现有电话模式、讲话打断、静音和家长时限继续生效。

## 选择预设音色

1. 启动应用并预热，打开家长空间，输入家长验证码解锁。
2. 在音色设置中选择“小芽原声”、两种中文女声或两种中文男声，点击试听。
3. 满意后点击“保存音色”。第一次使用会准备这个音色的开场和全部固定安全提示，期间显示“正在准备音色”。保持家长设置打开，等待完成。
4. 关闭家长空间，重新拨打小芽。新通话会固定使用所选音色；开场、普通回复和安全提示保持一致。

准备音色期间不能同时发起通话或准备另一个音色；其他设备正在通话时，请先挂断。准备失败仍保留原来已选音色，不会使用未准备完成的缓存。再次选择已准备好的音色通常更快。

## 录入自己的声音

本次开发没有使用你的真人录音，也没有生成或验证你的个人音色。现在可以直接在家长空间自行录入，无需把录音发给云服务。

1. 输入便于辨认的音色名称，例如“我的声音”。
2. 填写准备朗读的文字，或填写已有录音的准确逐字稿。文本为5–200字，必须与录音内容一致。
3. 确认录音是你本人或已经取得许可，并同意在本机保存供合成使用。
4. 点击开始录音，平常语速朗读，完成后停止。建议8–15秒清晰普通话；允许3–20秒。录制时页面显示红点和时长，到上限自动停止。
5. 试听参考录音，核对文字后点击“创建自定义音色”。创建仅保存参考样本，不会自动替换当前声音。
6. 选择新音色，试听合成效果，再点击“保存音色”，等待固定语音准备完毕。

可朗读以下例句，并把实际说出的内容填写为逐字稿：

> 你好，今天阳光很好。我们一起讲一个温暖的小故事，慢慢说，认真听，想到什么有趣的事情就分享出来。

也可以选择已有音频文件，最多10MB、时长仍为3–20秒。浏览器能解码的WAV、MP3等格式会在本机转换成16kHz单声道PCM16 WAV后提交；不支持的格式会提示转换失败。参考声音只有在点击创建后才保存。关闭设置、切到后台、取消或退出会停止麦克风并清除尚未提交的样本。

音色克隆使用参考声音的特征合成新句子，不需要训练一个个人大模型。相似度、口音、情绪和稳定性会随录音变化；试听能听清文字不等于已验证“像本人”。本次自动测试只用了明确的合成参考录音，未做本人相似度或实体手机声学评估。

## 录音与删除

最多保存3个自定义音色。参考录音、对应文字和该音色固定语音缓存位于当前数据目录的`voices/`，默认是`.runtime/data/voices/`，不作为公开网页文件提供。目录权限为本机用户访问，文件权限0600；没有上传云端，也没有放入源码交付包。

在家长音色设置中选择自定义音色后点击删除，会删除该音色的参考录音、逐字稿及固定语音缓存。正在使用它的通话会结束；如果它是当前选中音色，恢复为小芽原声。即使参考文件损坏，该条目也保留删除入口。预设模型音色不能从界面删除。

普通对话录音和转写依旧不保存。主动创建的参考录音是明确的例外。页面始终说明声音由AI合成，自定义音色不代表本人正在实时讲话。

## 本机部署与限制

这台机器已安装预设音色及克隆模型。重装时先完成原有模型安装，再运行：

```bash
cd /home/timocy/babybot
.venv/bin/python scripts/setup_voices.py
```

预设使用Kokoro int8；克隆使用ZipVoice-distill int8与Vocos。原声保留MeloTTS。模型来源、校验和与许可见[模型说明](../models/README.md)及[音色清单](../models/voice-manifest.json)。ZipVoice预训练权重为非商业许可，当前用途是家庭本地试用。

新增音色的生成回答最多保留40字内的完整短句，以适应本机CPU合成延迟；不会截断句中的指令来凑长度。原有审核、8秒单模型及12秒整轮期限继续生效。参考录音过长、主机繁忙或模型出错仍可能触发固定安全提示；若已选音色文件损坏，会要求大人重新选择。

新音色同一时间处理1轮语音；原声保持2轮。额外请求会明确提示忙，请稍后重试，不排长队。手机访问仍需要受信任HTTPS；当前电脑的虚拟麦克风测试不能替代真实手机与房间回声测试。

完整测试结果见[测试报告](TEST_REPORT.md)。模型原始说明：[Kokoro](https://k2-fsa.github.io/sherpa/onnx/tts/all/Chinese-English/kokoro-multi-lang-v1_1.html)、[ZipVoice](https://k2-fsa.github.io/sherpa/onnx/tts/zipvoice.html)。

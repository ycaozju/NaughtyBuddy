# 小芽使用手册

小芽让孩子与照护者一起编故事、猜谜和说话。这份手册面向家中负责启动电脑及陪同使用的大人。当前交付默认完全使用本机模型；孩子可能遇到听错、回答不准确或安全提醒，重要问题由现实中的大人判断。

## 首次启动

在当前电脑打开终端，执行：

```bash
cd /home/timocy/babybot
.venv/bin/python scripts/manage.py start
.venv/bin/python scripts/warmup.py
```

第二条命令预先加载识别、合成和对话模型，减少第一次说话时的等待。看到 `{"warmup": true}` 后，在Chrome打开 `http://127.0.0.1:8765`。浏览器在本机localhost/127.0.0.1地址可以请求麦克风权限。

模型服务使用8081端口，网页服务使用8765端口。若这些端口已被其他服务使用，启动脚本会拒绝接管；不要结束自己不认识的进程。应用日志位于 `.runtime/app.log`，模型启动日志位于 `.runtime/llm.log`。

## 家庭口令与家长验证码

在项目目录查看 `.runtime/credentials.json`。其中 `family_code` 是家庭口令，`parent_pin` 是家长验证码，两者不同，首次运行随机生成。它们不在网页源码中。

1. 点击“家长空间”，输入家庭口令，完成当前设备登录。
2. 再输入家长验证码，解锁使用时长和偏好设置。
3. 关闭家长空间后，设置重新锁定；即使不关闭，成人授权也会在10分钟后过期。

设备登录有效期为24小时。照护者可以正常开始、结束聊天，但修改时限、偏好或其他设备授权需要家长验证码。“结束其他设备的会话”会撤销其他已登录设备的权限；当前家长设备保留登录。

如要更换口令，在项目 `.env` 中设置不同且至少六个字符的 `BABYBOT_FAMILY_CODE` 与 `BABYBOT_PARENT_PIN`，重启后由家长执行撤销其他设备。不要将家长验证码告诉孩子或写进公开的配置、截图和报告。修改口令不会自动撤销此前已发放的登录Cookie。

## 拨打小芽，持续交流

选择一种玩法，保持默认的“连续通话”，再点击“拨打小芽”。首次使用时允许麦克风，小芽会说明AI身份和挂断方法。接通后像打电话一样直接说话：每轮无需再点击说话按钮，小芽播完就继续听你说。页面显示通话时长和剩余可用时间。浏览器开启麦克风和音频需要这一次点击与授权。

| 玩法 | 怎么玩 |
| --- | --- |
| 一起编故事 | 说“小兔子想去森林”，接着选择故事的发展。回答通常是一至两个短句。 |
| 猜个小谜语 | 听完谜面再猜；可以说“给个提示”“再说一遍”“告诉我答案”或“换一个”。目前有五道固定谜题。 |
| 说说今天 | 分享一件小事，例如“今天我画了一只猫”。 |
| 好奇为什么 | 问简单的问题，例如“为什么会下雨”。小模型的回答可能过于简单或不准确，请大人补充。 |

说完后默认等待约1.4秒再发送，让孩子有思考的空隙。单次说话接近18秒时会先发送这一段。小芽说话时可以插话；前端检测到持续的有效声音后会先在本机停播，再通知后端丢弃旧回复。

连续听不清时仍保持自动收音，只给出调整距离或手动切换的提示，不会擅自改成按住说话。需要时可自行选择“按住说话”，按住按钮说一句，松开后发送；也可切回“连续通话”。收音和打断依赖麦克风、距离及环境噪声，首次使用请由大人先试。

点击“静音”可暂时关闭语音输入，已在播放的回复可以继续听；点击“取消静音”恢复收音，不需要重新拨打。静音期间仍占用通话时长。安全提示播完后也会继续听，不会因为一次审核降级自动挂断。

“用键盘说一句”是折叠的辅助入口，供成人调试或不方便说话时使用。当前版本仍需启动语音会话及麦克风才能使用此入口。

## 停止与离开页面

点击“挂断”会立即停止本地播放、关闭麦克风并结束会话；不会为了告别继续播音。也可以说“挂断”“挂电话”“结束通话”，原有“停止”“停一下”“不玩了”和“再见”仍有效。语音挂断需要先完成识别，紧急停播请直接点按钮。

切换到其他页面、隐藏当前页面、断网或离开应用时，前端会清理麦克风与播放资源。服务端同时有心跳超时清理。回到网页需要重新拨打，不会自动恢复录音。

浏览器自动播放、切后台和锁屏行为在不同设备上不同。已验证当前电脑Chromium的资源清理；手机实物场景仍需按后文检查。

## 选择音色或使用自己的声音

家长解锁后可在音色设置选择四种中文预设声音，也可录制或上传自己的声音并填写对应逐字稿。先试听，再保存；第一次保存会准备同音色的开场和固定安全回复，完成后重新拨打生效。支持静音、插话和语音挂断。完整步骤及参考录音删除方法见[音色使用指南](VOICE_GUIDE.md)。

## 家长设置

默认每次10分钟、每天20分钟；可在家长空间调低。每天额度按Asia/Taipei时区跨日重置，同一家庭多个会话的使用时间会累加，等待模型的时间也计入。

可设置每天允许开始和最晚结束的整点，默认0至24点；结束时刻必须晚于开始时刻，当前不支持跨午夜的时段。后台会检查正在进行的会话，达到时限或超出允许时段会结束。即使用户不断发送心跳，也不能延长时限。

“等孩子想一想”调整静音等待长度。孩子经常被抢话时，可选择2秒或2.5秒；等待越长，回答启动也越晚。不要单纯为追求快而缩短到孩子说不完一句话。

“让所有设备立即休息”会结束当前所有会话，但不永久禁止重新开始。如需限制后续使用，同时调整时段或每日额度。

## 记忆与隐私

记忆默认关闭。开启后，只保存大人从固定列表里选择的至多五个话题，例如恐龙或太空；聊天内容不会自动进入长期记忆。请把选中的内容告诉孩子。

关闭“记住喜欢的话题”后，后续生成不再使用保存的偏好；原选项仍可由大人查看。“清除偏好”会删除这些选项并关闭记忆，同时清空正在进行的后台对话上下文、取消待播放回复。

当前会话中，后端只把浏览器确认完整播放的回答写入短期上下文，最多保留六组问答。未播完的回答不当作孩子已经听过。退出后清除后台短期上下文；页面上已有的文字仍可能可见，刷新页面即可清空界面显示。

日常数据库只保存设置、选定偏好、使用时长和登录令牌的哈希。默认不保存对话录音、转写或聊天历史。家长主动创建自定义音色时，会在本机另存参考录音及逐字稿，删除音色会同时删除它们与相关语音缓存。报告目录中的语音及文字是开发时人工构造的合成测试样本，不是孩子的录音。

## 常见情况

| 看到或遇到的情况 | 处理办法 |
| --- | --- |
| 浏览器没有麦克风选项 | 使用更新的Chrome，并确认本机地址或受信任的HTTPS；手机访问普通HTTP局域网IP通常不能开麦。 |
| 没声音 | 检查系统音量、输出设备及页面播放权限；结束后重新开始。已播出文字不意味着扬声器一定有声音。 |
| 小芽把外放声音当作孩子说话 | 降低外放音量、调整手机位置，先使用按住说话；有条件时测试耳机。不要把自动打断视作已通过所有房间的回声测试。 |
| 总是听错 | 靠近麦克风、一次说短一点、延长思考停顿，或用按住说话。真实童声识别率尚未测量。 |
| 提示现在有点忙 | 默认最多四个连接、两个同时处理的轮次。结束其他设备的会话后稍等重试；不要反复快速点击。 |
| 提示换个安全玩法 | 输入规则、输出规则或独立审核触发了固定回应；审核也可能误判，可换一种表达或由成人检查。 |
| 模型暂时不可用 | 应用会使用预录安全话术，或文字提示休息；不会跳过审核继续播放生成回答。用 `manage.py status` 检查服务。 |
| 第一次很慢 | 运行预热命令；检查电脑是否同时在做重型编译、仿真等工作。不要通过提高超时让孩子等很久。 |
| 今天不能再开始 | 查看家长空间的每日额度与允许时段。测试脚本也消耗所连接家庭的额度。 |

## 手机上使用

本次默认只开放电脑回环地址，因此直接在手机输入电脑IP不能访问当前默认配置。给手机使用时，需要由维护者准备覆盖该地址或域名、且已被手机信任的HTTPS证书。仅忽略自签名证书告警不等于完成安全上下文配置。

完成证书准备后，在 `.env` 中设置明确的来源地址，并开启安全Cookie，例如：

```dotenv
BABYBOT_ORIGINS=https://你的局域网主机名:8765
BABYBOT_SECURE_COOKIE=1
```

再使用已有证书启动，参数中的路径须替换为真实绝对路径：

```bash
.venv/bin/python scripts/manage.py restart --host 0.0.0.0 --port 8765 \
  --cert /绝对路径/server.crt --key /绝对路径/server.key
```

只让可信家庭网络访问应用端口，不向手机开放8081模型端口。启动脚本不会自动配置证书、手机信任、系统防火墙或公网映射；这些不是本次已验证的交付项。也不默认支持微信内置浏览器、后台持续收音或锁屏对话。这里的“电话”指网页内持续语音会话，不会拨打手机号码或接入运营商电话。

第一次用实际Android手机，由大人逐项检查：麦克风授权、外放与耳机、轻声说话、句中停顿、连续五轮、讲话打断、结束按钮、切应用、锁屏、断网和重新打开。确认后再陪同孩子试用。iPhone/iPad也需各自验证。

## 服务切换与关闭

默认本地模式需要同时运行本机LLM、ASR和TTS。Qwen、豆包、DeepSeek的云端文本预设可以通过 `.env` 显式配置，具体字段见 `.env.example`；含密钥的配置文件应执行 `chmod 600 .env`，仅供本机用户读取。语音识别、合成和独立审核仍在本机，故障不会自动切换供应商。这三个云端预设没有做真实付费账号接入验收；启用前应先由成人核对儿童场景与数据留存条款，再用成人测试数据验证。

网页在云端文字模式下会提示“大人已启用云端文字服务”；此时文字上下文会发往选定供应商，不能再当作完全本地处理。

不用时执行 `.venv/bin/python scripts/manage.py stop`。再次使用先启动，再预热。重启电脑后不会自动开机自启，也没有安装系统服务。

交付前已停止本项目的测试服务，0.1.0验收数据库保留在 `.runtime/acceptance-data-*`，0.2.0电话测试数据库保留在 `.runtime/call-test-data`，0.3.0音色测试保留在 `.runtime/voice-test-data`；本轮没有修改默认的 `.runtime/data`，避免测试消耗孩子的每日额度。源码交付包不包含该测试数据库、凭据、虚拟环境或模型权重；当前机器上的这些本地资源仍可供启动使用。

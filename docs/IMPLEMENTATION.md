# 小芽实现文档

版本：0.3.0；核对日期：2026-10-13。本文描述当前源码与本机部署。操作步骤见[使用手册](USER_MANUAL.md)，验证结果与限制见[测试报告](TEST_REPORT.md)。本次交付是家庭本地试用版本，没有部署到云端或公开发布。

## 1. 架构与文件

浏览器负责采音、断句、立即停播和播放确认；FastAPI单进程负责认证、会话、安全决策及资源限制；本地模型完成ASR、文本生成、独立回复审核和TTS。普通一轮依次执行“完整语音段→识别→输入规则→生成→输出规则→模型审核→合成→播放确认”。整次短回答审核通过后才合成，不边生成边播放。

| 文件 | 职责 |
| --- | --- |
| `static/app.js`、`pcm-worklet.js` | 页面状态、麦克风、VAD、重采样、播放及打断 |
| `babybot/app.py` | HTTP/WS接口、会话、计时、限流、取消和ACK |
| `safety.py`、`games.py` | 安全路由、短句清理、固定话术、五题谜语库 |
| `voices.py`、`voice_engine.py` | 私有参考录音、音色快照、同音色安全缓存、Kokoro/ZipVoice |
| `providers.py`、`adapters.py` | 真实本地模型；三个可选云文本预设 |
| `config.py`、`storage.py` | 环境配置、凭据、SQLite设置和使用统计 |
| `scripts/` | 安装、预录、启动停止、预热和验收脚本 |
| `tests/`、`reports/` | 自动化用例、合成测试素材和实际结果 |

故事、闲聊、好奇问答使用LLM。猜谜因小模型曾生成矛盾线索，改用固定题库，支持提示、公布答案、换题和放弃；响应标为`source=curated`，仍需输出规则和模型审核。

## 2. 音频采集与轮次判断

点击拨打后才申请麦克风，请求浏览器回声消除、降噪和自动增益。AudioWorklet把实际采样率转换成16kHz单声道Int16，以320采样点、20毫秒为一帧发送到页面。转换采用跨帧相位累加与区间平均；不是专业音频重采样器。Worklet输出保持静音，避免把麦克风信号直接外放。

VAD使用RMS能量和缓慢更新的噪声底线。普通采音连续3帧达阈值开始；播放中在300毫秒窗口内累计至少200毫秒有效声音，允许中文音节之间的短空隙，固定最低阈值0.022并结合噪声底线。保留300毫秒前导音频；静音默认1.4秒结束一句，可由家长设为0.8–3秒。至少160毫秒有效声音才提交，前端18秒截断、后端20秒上限。整个语音段通过WS二进制帧提交，未实现流式ASR。

默认连续通话，识别失败只提示重说，不自动转为按住说话；PTT必须由用户明确选择。电话状态包含接通中、通话中、静音和挂断，分别展示累计与剩余时间。静音同时关闭输入轨道并丢弃Worklet帧、清空尚未发送的语音，取消静音后继续同一WS会话；静音不暂停后台计时。按住说话、插话和挂断都先在本地停止播放，再通知服务器。切后台、离线或麦克风断开会停止采集和播放；回到页面需重新开始。真实Android手机外放回声、轻声童音和思考停顿仍需陪同实测。

## 3. 协议、取消与记忆提交

登录后使用同源Cookie连接`/ws`。控制消息是JSON，语音消息为无WAV头的16kHz、单声道、16位小端PCM。

| 方向 | 主要消息 |
| --- | --- |
| 浏览器→服务端 | `start(mode)`、`text(text)`、`interrupt`、`stop`、`ping`、`played(turn_id,chunk_id)` |
| 服务端→浏览器 | `session_started`、`state`、`transcript`、`audio`、`greeting`、`interrupted`、`pong`、`error`、`ended` |

`audio`携带`turn_id/chunk_id`、文本、Base64 WAV、`mime=audio/wav`、`safety=approved`、来源及各阶段耗时。开场身份说明使用独立`greeting`事件、`turn_id=0`，不能把它计作生成回答或端到端成功；其音频也来自预录缓存。

每次新轮次或打断递增epoch。模型步骤返回后检查epoch，过期结果丢弃；前端另以退役轮次集合及播放版本号丢弃延迟音频、解码回调和打断确认。只有浏览器播放自然结束才发送`played`，服务端核对两个ID后写入内存历史并推进谜语状态。历史最多12条消息；被打断的整句不提交，没有实现逐词播放进度记忆。

## 4. 内容控制与故障路径

输入规则区分停止、危险操作、伤害讲述、情绪困扰、隐私、身体边界、依赖和提示注入。带句末标点的停止短语，以及“挂断”“挂电话”“结束通话”等精确指令也会结束会话。伤害讲述使用支持性固定话术，不自动通知任何人。生成文本去除思考段、编号和格式符号，只保留最多两个完整短句、总长80字符以内，丢弃未完成尾句。

输出规则通过后另发一次无对话历史的审核调用，以JSON提供当前语境和回复，必要时附最近上下文。语法仅允许`ALLOW/DENY`，只有严格`ALLOW`放行。审核异常、超时或拒绝时不合成该生成内容；改播固定安全话术。审核与生成复用Qwen权重，是独立调用，不是独立训练的安全模型。

预录包括9类安全回复及1条AI身份开场。准备脚本保存文本和音频哈希，服务启动时复核后载入；缺失时只能临时合成固定文本，仍失败则显示文字。原始模型分类测试18/20：存在一次假装真人漏判和一次安全劝停误拒；已补规则拦截已知真人表述，不能据此保证同义表达均被覆盖。

0.2.0的安全回应和相关错误增加`reason_code`。`recognition_unclear`表示空白或过长转写；`input_policy`、`output_rule`、`review_denied`分别表示输入规则、输出规则和审核未放行。`asr/llm/review/tts`加`_error`或`_timeout`区分对应阶段失败；整轮期限到期为`turn_timeout`，无法归入模型阶段的应用错误为`internal_error`。固定话术也无法合成时，保留原原因并增加`delivery_reason_code=tts_error/tts_timeout`，返回可恢复的文字提示，继续监听下一句。

`/api/admin/status`的`metrics`返回进程内`fallback_<reason_code>`计数，固定话术交付失败另计`fallback_delivery_<delivery_reason_code>`。这些计数重启清零，没有持久保存候选答案。固定话术缓存缺失时的本地合成有独立10秒期限；它发生在普通整轮12秒期限之外，因此最坏情况可能再等待固定话术交付。正常部署已预录固定音频，无需临时合成。

## 5. 模型、并发与超时

采用Qwen2.5-1.5B Q4_K_M、SenseVoiceSmall int8和MeloTTS-Chinese，全部CPU运行。版本、来源、许可及SHA-256见[模型说明](../models/README.md)。llama.cpp监听回环8081，4个生成及批处理线程、2个槽、总上下文8192、轮询关闭；本地生成最多96 tokens。ASR/TTS各用2个推理线程，输出WAV为44.1kHz。

应用默认最多4个WS连接、2轮处理中请求；握手前预占连接名额，忙时立即返回`overloaded`。每连接每分钟20次输入，每会话60轮，文本最多300字符。单模型等待8秒、回复审核4秒、整轮12秒。ASR/TTS分别使用单工作线程执行器；任务取消后，许可直到原生推理真正结束才释放，避免并发重入。取消不等同于即时终止底层CPU计算。

前端每5秒心跳，服务端20秒未收到消息则清理。默认每次10分钟、每日20分钟；服务器每秒检查剩余时间和允许时段，统计使用Asia/Taipei日期，多个活跃会话分别累计秒数。

## 5.1 本地音色与参考声音

0.3.0在原有单TTS线程执行器内新增Kokoro int8和ZipVoice-distill int8/Vocos。`synthesize(text, voice=None)`接收服务器生成的独立音色快照；默认Melo输出44.1kHz，新增模型输出24kHz WAV。模型按引擎缓存，不修改共享speaker或reference状态。ZipVoice参考录音在每次合成时从私有路径读取，不训练或持久保存个人模型权重。

新音色的模型生成回答最多40字，提示词要求短句，清理只保留完整句；无法满足长度的长句会被拒绝，不在句内截断。固定题库与安全话术不裁剪。实测长句和长参考音频可能超时，因此新音色最多同时处理1轮，Melo仍为2轮；4个连接上限、8秒模型与12秒整轮期限不变。超过容量明确返回`overloaded`。

家长专用API如下，均要求家长权限，修改请求同时检查Origin：

| 方法与路径 | 行为 |
| --- | --- |
| `GET /api/voices` | 返回音色目录、当前选择、模型可用性与录音长度/数量限制，不返回参考文字或文件路径 |
| `POST /api/voices` | 接收名称、准确逐字稿、Base64 WAV及明确许可；生成随机音色ID，不接受客户端路径或模型配置 |
| `POST /api/voices/preview` | 只合成固定试听句，返回WAV和`X-Voice-Id`，不开放任意未审核文本入口 |
| `POST /api/voices/select` | 准备并验证同音色的10条开场/固定安全语音后保存选择，下一次通话生效 |
| `DELETE /api/voices/{id}` | 删除自定义参考录音、逐字稿与缓存；结束使用该音色的会话并恢复默认选择 |

只有上传路由在家长身份验证后才允许最多2MiB请求体，其余原有16KiB限制保留。上传音频进一步限制为3–20秒、PCM16/16kHz/单声道，拒绝空白音频及截断WAV；最多3个自定义音色。浏览器解码上传或录制的素材并规范化，关闭/取消/锁定时释放录音轨道、试听和未提交字节。

音色准备和试听互斥，且不与活动通话竞争。固定语音准备总期限120秒，各次原生调用仍受模型8秒限制；全部成功后才写完整缓存manifest并提交选择，结束前再次检查家长授权。缓存manifest校验音色快照、话术指纹和每条WAV哈希。会话固定音色快照，`session_started/greeting/audio`携带实际`voice_id`。删除与准备期间已连接但尚未开始的会话也不能插入启动。

参考录音及逐字稿保存于数据目录`voices/profiles/<随机ID>`，固定语音位于`voices/cache/<音色ID>`；权限分别为0700目录/0600文件。损坏的参考条目仍可删除。它们不通过静态资源提供，也不打包进源码；普通对话录音仍不保存。详见[音色指南](VOICE_GUIDE.md)。

## 6. 权限、数据与部署边界

家庭口令取得儿童权限，独立家长PIN解锁设置10分钟。会话Cookie为HttpOnly、SameSite=Strict，有效24小时；HTTPS部署需启用Secure。修改时间、主题偏好、清除记忆、撤销其他登录和结束当前全部会话需要家长权限。登录与解锁分别限速；HTTP修改请求和WS检查Origin，Host白名单、CSP和请求大小限制同时生效。

SQLite只保存设置、固定主题偏好、登录令牌哈希和每日使用秒数；历史统计没有自动过期清理。原始凭据保存在权限0600的本地文件，数据目录0700。主题记忆默认关闭，只能从预置主题选最多5个。对话录音、转写、回复和短期历史不写数据库或应用日志；内存历史随会话结束清除。浏览器当前气泡及测试报告中的合成素材与应用持久记忆是不同的数据范围。

默认应用只监听本机8765。手机使用需另配置局域网可达地址、准确Origin和受信任HTTPS；未经配置的HTTP局域网地址通常不能开启麦克风。部署保持一个Uvicorn worker，否则内存连接和并发配额无法跨进程统一。`manage.py`按PID及进程启动标识管理本项目服务，不接管其他进程。

云端`qwen/doubao/deepseek`仅是受限文本生成预设，显式配置密钥及模型后才启用；会发送文本上下文，ASR、TTS及审核仍在本机。三个预设只有MockTransport验证，无云账号实测。Provider接口可替换实现，但尚未适配云ASR/TTS。

## 7. 验证结论与后续

0.3.0后端132项、前端33项控制回归通过；音色真实模型、浏览器与并发结果见测试报告。0.2.0后端92项、前端21项控制回归也保留原件。0.1.0基线已完成真实模型端到端6场景及150请求主压力测试。主压力中67次生成、3次安全固定回复、80次明确过载拒绝，无超时或传输异常；严格判定仍为`passed=false`。加强安全策略后端到端严格4/6，两个正常输入触发降级；30请求回归为13次生成、1次安全降级、16次过载。扩大37条审核样例后独立审核34/37，新增窗台跳跃和触摸热锅两条漏判已补确定性规则及回归，未采用降低拒绝但增加漏判的候选提示。不能写成“全部测试通过”。浏览器、延迟目标和各项失败原因以测试报告为准。

未验证真实儿童识别率、长期陪伴效果、所有安全表达、多型号Android的声学回声和后台行为、云服务真实兼容性或多家庭规模。当前适合家长陪同进行本地试用；后续优先补真实设备验收及内容质量样本，而非扩大并发。启动、预热、关闭及排障见使用手册，服务无需保持常驻。
